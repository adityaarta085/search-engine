# AI Search Engine

A modern, AI-powered search engine built with Next.js and Brave Search API.

## Features

- **Brave-Powered Search**: High-quality, privacy-first web, image, video, and news search results.
- **AI Summaries**: Instant, context-aware summaries generated by Brave Summarizer.
- **Premium UI**: Modern SaaS-style design with smooth animations using Framer Motion.
- **Customizable**: Dark/Light mode, layout density options, and AI toggle.
- **Performance**: Optimized with Next.js 15, Turbopack, and Vercel Edge compatibility.

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS v4
- **Search API**: Brave Search API
- **AI**: Brave Summarizer
- **Animations**: Framer Motion
- **Icons**: Lucide React
