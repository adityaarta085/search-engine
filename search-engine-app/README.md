# AI Search Engine

A modern, AI-powered search engine built with Next.js, Google Search API, and Gemini.

## Features

- **Google-Powered Search**: High-quality web, image, and video search results.
- **AI Summaries**: Instant, context-aware summaries generated by Google Gemini.
- **Premium UI**: Modern SaaS-style design with smooth animations.
- **Customizable**: Dark/Light mode, layout density options, and AI toggle.
- **Performance**: Optimized with Turbopack and Vercel Edge compatibility.

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS v4
- **AI**: Vercel AI SDK + Google Gemini
- **Animations**: Framer Motion
- **Icons**: Lucide React
